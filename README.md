# NumPy, SciPy, Pandas e Matplotlib — Inteligência Artificial

Resolução de 80 exercícios das principais bibliotecas Python para análise de dados e computação científica.

## Conteúdo

- **Exercícios 1-20: NumPy** — Arrays, operações matemáticas, álgebra linear
- **Exercícios 21-40: SciPy** — Integração, otimização, equações diferenciais
- **Exercícios 41-60: Pandas** — DataFrames, filtros, agregações, I/O
- **Exercícios 61-80: Matplotlib** — Gráficos, visualizações, customização

## Instalação

```bash
pip install numpy scipy pandas matplotlib openpyxl
```

## Como Usar

Execute os arquivos `.py` ou abra no Jupyter/VS Code.
